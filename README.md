# Customer Churn Analysis Dashboard

Customer Churn Analysis: Interactive Power BI Dashboard**

An interactive data visualization dashboard built to analyze customer churn patterns, identify high-risk customer segments, and understand the factors influencing customer retention.

## 2. Short Description / Purpose

The Customer Churn Analysis Dashboard is a Power BI report designed to explore customer behavior and identify trends associated with customer attrition. It presents key performance indicators such as total customers, total churn, churn rate, and new joiners, with visual analysis by gender, age group, state, payment method, contract type, internet service, tenure, and churn reasons. A separate prediction dashboard displays predicted churners and customer-level details to support data-driven retention strategies.

## 3. Tech Stack

The dashboard was developed using the following tools and technologies:

- **Power BI Desktop** – Main data visualization platform used to create the dashboard.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Used for calculated measures and KPI calculations.
- **Data Modeling** – Organizing data and relationships to support analysis.
- **File Format** – `.pbix` for the Power BI report and `.png` for dashboard previews.

## 4. Data Source

The project uses customer data containing demographic details, service subscriptions, account information, contract types, tenure, and churn status or reasons.

The data is used to analyze customer behavior, compare churn rates across different customer segments, and identify patterns associated with customer attrition.

## 5. Features / Highlights

- **Business Problem:** Customer churn can affect business revenue and long-term customer relationships. Understanding why customers leave can help businesses improve retention.
- **Goal of the Dashboard:** Analyze churn patterns and identify customer segments with higher churn rates.
- **KPI Overview:** Displays total customers, new joiners, total churn, and churn rate.
- **Customer Segmentation:** Analyzes churn by gender, age group, and state.
- **Service Analysis:** Compares churn rates by internet type, payment method, and subscribed services.
- **Contract and Tenure Analysis:** Explores churn patterns across contract types and customer tenure groups.
- **Churn Reasons:** Highlights reported reasons for customer attrition.
- **Churn Prediction:** Displays predicted churners and customer-level details in a separate dashboard.
- **Interactive Visualizations:** Presents customer insights through charts, tables, and KPI cards.

## 6. Objective

To transform customer data into meaningful insights, understand customer churn patterns, identify segments that may require attention, and support data-driven decisions to improve customer retention.
